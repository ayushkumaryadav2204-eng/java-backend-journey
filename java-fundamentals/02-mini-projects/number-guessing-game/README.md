# 🎯 Number Guessing Game

A simple **Java console-based game** where the computer randomly selects a number between **1 and 100**, and the player tries to guess it.

## 🧠 Concepts Practiced

* Variables & data types
* `Scanner` for user input
* `Random` for random numbers
* `if-else` conditions
* `do-while` loop
* Comparison & increment operators
* Basic problem-solving and program logic

## ▶️ How to Run

Compile:

```bash
javac NumberGuessingGame.java
```

Run:

```bash
java NumberGuessingGame
```

## 🎮 How It Works

* The computer generates a random number from **1–100**.
* The user enters a guess.
* The program tells whether the guess is **too high** or **too low**.
* The game continues until the correct number is guessed.
* The number of attempts is displayed.
