# 🧮 Java Calculator

A simple **console-based calculator** built using Java as part of my **Java Backend Journey**.

This project applies Java fundamentals to build a small interactive calculator that accepts user input and performs basic arithmetic operations.

---

## 🎯 Objective

Build a calculator that can:

- Accept two numbers from the user
- Accept an arithmetic operator
- Perform the selected calculation
- Display the result
- Handle division by zero
- Handle invalid operators

---

## 🧠 Concepts Used

- Variables
- `double` data type
- `char` data type
- `Scanner`
- User input
- Arithmetic operators
- `switch` statement
- `if` statement
- `break`
- `return`
- Basic error handling

---

## ⚙️ Features

- [x] Addition `+`
- [x] Subtraction `-`
- [x] Multiplication `*`
- [x] Division `/`
- [x] Modulus `%`
- [x] Division by zero handling
- [x] Invalid operator handling
- [x] Console-based user interaction
